# 疾病発生率パネル 設計書（再現環境版）

> **本ドキュメントの範囲について**
> 原本の設計書は、個人医療保険の経験率（A/E）分析システム全体を対象としていました。
> 本再現環境では実績の保有（In-Force）・異動（Movement）・請求データを使用せず、
> 経験率分析も利用しないため、該当機能（`ins_*` テーブル群、YAML 駆動インポータ、
> `analyze` / `analyze-benchmark`、Web UI）は配布物から除外しています。
> 本書もそれに合わせ、**人口統計から疾病発生率パネルを構築する経路のみ**を記述します。
> 除外部分を含む原本は `ICA/ValidationTools/EAS/docs/設計書.md` を参照してください。

## 1. 目的と範囲

e-Stat（患者調査・人口動態統計）および全国がん登録から、
疾病別・性別・年齢階級別の発生率パネルを統一スキーマで構築し、
Scale BB / APC 拡張モデルの入力として供給することを目的とする。

- 出典・品質の異なる複数の率（`rate_type`）を単一テーブルに正規化して保持する
- 出典ごとの品質を `quality_flag` として明示し、下流で選別できるようにする
- SQL Server 等の外部 RDBMS に依存せず、SQLite 単体で完結する

## 2. システム構成

| 層 | 実装 | 責務 |
| --- | --- | --- |
| データ層 | SQLite (`experience_rate.db`) | `population_incidence` / `rider_def` / `scalebb_*` 等の永続化 |
| パネル構築層 | `scripts/build_*_panel.py` | 生データ → 各 `rate_type` のパネル CSV 生成・統合 |
| モデル層 | `src/experience_rate/_scalebb_core/` | 2D Whittaker-Henderson 平滑化・APC 分解・世代投影 |
| UI 層 | CLI (`cli.py`) | 対話的な操作・結果表示・CSV 出力 |

## 3. データモデル

`sql/01_schema.sql` で定義。

| テーブル | 用途 |
| --- | --- |
| `parameters` | 観察年度終了月・事業年度終了月の単一行 |
| `rider_def` | 特約マスタ（`rider_code` / `rider_name` / `rider_category` / `description`） |
| `population_incidence` | 人口発生率パネル（rate_type × disease × year × sex × age） |
| `rider_disease_map` | 特約と疾病発生率のマッピング |
| `scalebb_run` | Scale BB / APC の実行メタ（パラメータを `config_json` に保持） |
| `scalebb_improvement` | fit 結果（age × year の観測率・平滑化率・改善率） |
| `scalebb_cohort_effect` | APC のコホート効果 γ |
| `scalebb_projection` | 投影結果（age × year の改善率・投影率・観測フラグ） |
| `predicted_rate_generational` | 発行年別 1D 予定発生率テーブル |

> `rider_def` / `rider_disease_map` は特約と疾病の対応表であり、
> 契約データを伴わない本環境では発生率の参照系メタデータとしてのみ機能する。

## 4. データフロー

```
        data/RowData/  (e-Stat / 全国がん登録の生データ)

```

## 5. 疾病発生率データソース

| `rate_type` | 出典 | 品質 | 対象期間 | 用途 |
| --- | --- | --- | --- | --- |
| `registry` | 全国がん登録 (NCR) | **A** (真罹患率) | 2016-2023 | がん罹患率の最高品質ベンチマーク |
| `initial_visit` | 患者調査 Z70 (外来初診受療率) | B (近似) | 2023 断面 | 生活習慣病・初診フロー |
| `discharge` | 患者調査 Z10 + H20-47 平均在院日数 | C (近似) | 2023 断面 | 入院給付系 |
| `mortality` | 人口動態統計 5-15 (粗死亡率) | D (下限) | 1950-2020 | 致死性疾患の下限値。**予定発生率表の入力** |

### 5.1 各 rate_type の計算式

- **registry**: 全国がん登録の年齢階級別罹患数 ÷ 日本人人口 (そのまま 1 人年率)。
- **initial_visit**: Z70 の「調査日 1 日あたり人口 10 万対の外来初診受療率」を
  年率に換算。
  - `rate_per_year ≒ rate_per_100k × config.incidence.initial_visit_annual_days
    / 100,000 × config.incidence.initial_visit_duplicate_adjust`
- **discharge**: Z10 の退院数 × 365 ÷ 在院日数を分母に換算した年率。
- **mortality**: 人口動態の粗死亡率 (10 万対) を 1 人年率に変換。

> 予定発生率テーブルの入力は `mortality`（死因別死亡率）である点に注意。
> `registry` は入力ではなく、真の罹患率としての A-tier ベンチマークに用いる。
> 詳細は一つ上の階層の `../../README.md` §1 を参照。

## 6. 既知の制約

| 項目 | 本再現環境 |
| --- | --- |
| 発生率の代理性 | 死因別死亡率を疾病発生率の代理として使用（罹患率との乖離は今後の課題） |
| `initial_visit` / `discharge` | 2023 年の単一断面のみ。時系列モデルの入力には不足 |
| 年齢階級 | 5 歳階級が基本。単年齢は `scalebb-gen-table` の log-linear 補間で生成 |
| 経験率 (A/E) 分析 | 契約データを扱わないため対象外（機能ごと除外） |
