# Figures

The figures that appear in the paper and the ICA 2026 presentation, so you can
look at them at full resolution without running anything.

All of them except Figure 8.1 are regenerated by `bash run_all.sh` in
`../reproduction/backtest/` — the committed copies here and the ones the script
writes are the same files.

| Figure | Content | Generated by |
|---|---|---|
| `fig_3_1_input_panel_overview.png` | Input panel: cause-specific mortality 1950–2024 (§3.1) | `make_paper_figures.py` |
| `fig_3_2_smoothing_before_after.png` | Two-dimensional Whittaker-Henderson smoothing, before vs after (§3.2.1) | `make_paper_figures.py` |
| `fig_3_3_blend_schematic.png` | Blending observed improvement rates toward the long-term rate (§3.2.2) | `make_paper_figures.py` |
| `fig_4_1_backtest_design.png` | The 3-cutoff backtest design (§4.2) | `make_paper_figures.py` |
| `fig_5_1_overall_mape_bias_by_year.png` | Yearly MAPE and relative bias by disease (§5.1) | `run_backtest.py` → collected |
| `fig_5_2_heart_disease_total_trajectory.png` | Heart disease: observed, smoothed, projected vs actual (§5.1) | `run_backtest.py` → collected |
| `fig_5_3_cancer_total_trajectory.png` | Cancer: the same trajectory view (§5.1) | `run_backtest.py` → collected |
| `fig_5_4_scalebb_gap_vs_best_baseline.png` | Scale BB-D MAPE minus best-baseline MAPE (§5.2) | `compare_cutoffs.py` → collected |
| `fig_5_5_scalebb_cutoff_comparison.png` | Scale BB-D MAPE by training cutoff (§5.3) | `compare_cutoffs.py` → collected |
| `fig_6_1_scalebb_directional_per_cutoff.png` | Directional accuracy by training cutoff (§6.1) | `compute_directional_accuracy.py` → collected |
| `fig_6_2_scalebb_vs_loglin_directional.png` | Directional accuracy: Scale BB-D vs `loglin_trend` (§6.3) | `compute_directional_accuracy.py` → collected |
| `fig_6_3_calibration_recovery.png` | Recalibration experiment for direction-reversing diseases (§6.5) | `make_calibration_recovery_figure.py` |
| `fig_8_1_bel_sensitivity_bar.png` | BEL sensitivity by model point and scenario (§8.4) | **not reproducible here** — see below |

**Figure 8.1** comes from the BEL sensitivity demonstration of §8, which is a
separate liability-valuation model built on the ESR implementation details
(risk-free curve and stress factors set by regulatory notice). That model is not
part of this repository; the figure is included because it is one of the results
shown in the presentation. Everything else here is reproducible from the code
and data in this repository.
